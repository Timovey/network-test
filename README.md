# speedtest

Консольный скрипт для замера скорости скачивания. Делает 10 последовательных HTTPS-запросов к указанному адресу, дожидается полного ответа на каждый и выводит среднее время запроса, общий объём и скорость.

## Требования

Node.js 22 или новее. Зависимостей нет, `npm install` не нужен.

## Запуск

```
node speedtest.mjs <https-адрес>
```

Пример:

```
node speedtest.mjs https://proof.ovh.net/files/10Mb.dat
```

Адрес с `?` возьмите в кавычки:

```
node speedtest.mjs "https://speed.cloudflare.com/__down?bytes=10000000"
```

## Вывод и единицы измерения

Пример вывода для файла 1 МБ:

```
Начало скрипта
#1: 1048576 байт за 2077 мс
#2: 1048576 байт за 1384 мс
...
#10: 1048576 байт за 910 мс
Среднее время запроса: 1198 мс
Всего скачано: 10.00 МБ
Скорость: 0.83 МБ/с
```

| Строка | Единица | Как считается | Пример |
|---|---|---|---|
| `#N: ... байт за ... мс` | байты, миллисекунды | размер тела ответа и время от начала запроса до получения последнего байта | `1048576 байт за 2077 мс` |
| Среднее время запроса | мс, округлено до целого | сумма времени всех запросов / 10 | `1198 мс` |
| Всего скачано | МБ, 2 знака после запятой | сумма байт / 1024 / 1024 | `10.00 МБ`|
| Скорость | МБ/с, 2 знака после запятой | всего МБ / суммарное время в секундах | `0.83 МБ/с` |


## Файлы для проверки

- `https://proof.ovh.net/files/1Mb.dat` — 1 МБ
- `https://proof.ovh.net/files/10Mb.dat` — 10 МБ
- `https://proof.ovh.net/files/100Mb.dat` — 100 МБ
- `https://nbg1-speed.hetzner.com/100MB.bin` — 100 МБ

Скрипт скачивает файл 10 раз, поэтому для 100 МБ получится 1 ГБ трафика.

## Ошибки

При ошибке скрипт выводит одну строку `Ошибка: ...` и завершается с кодом 1:

| Ситуация | Сообщение |
|---|---|
| адрес не указан | `Ошибка: не указан URL адрес` |
| адрес некорректен | `Ошибка: некорректный адрес: ...` |
| адрес не начинается с `https://` | `Ошибка: поддерживается только https: ...` |
| сервер ответил не кодом 2xx | `Ошибка: сервер ответил 404` |
| сервер 30 секунд не присылает данных | `Ошибка: нет ответа от сервера 30 с` |
| соединение оборвалось посреди скачивания | `Ошибка: соединение оборвалось, получено N байт` |

Таймаут считает время простоя, а не общее время запроса: большой файл на медленном канале он не прервёт, пока данные продолжают приходить.

Любая ошибка останавливает весь замер. Если, например, упал 5-й запрос, итог по первым четырём не выводится.
